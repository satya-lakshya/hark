Privacy

Last updated: 19 September 2026

Hark is in early beta. If this document and the app ever disagree, the app is wrong and we want to know.

The short version

The app reads text aloud on your Mac. To describe code, it sends code blocks to Google. Nothing else you read leaves your machine, and none of it is stored anywhere by us.

What the app can see

To find the newest reply in a chat app, the app uses macOS Accessibility. That means it can read the contents of the window in front of you and press that app's own copy button. macOS asks your permission before any of this works, and you can withdraw it in System Settings at any time.

The app only looks when you press the hotkey. It does not watch your screen in the background.

It also briefly uses your clipboard: it copies the reply, reads it, and puts back whatever you had there before.

What leaves your Mac

Code blocks. When a reply contains code, that code is sent to Google's Vertex AI so a model can describe it in a sentence. Google processes it under their own terms. Nothing about the surrounding conversation is sent, only the code, and at most the first 800 characters of each block.

You can turn this off under Playback. With it off, nothing you read ever leaves your machine, and code blocks are announced as "here's a code example" instead.

Nothing else. The speech itself is generated on your Mac by a local model. The text of what you read is never uploaded, never logged, and never stored by us.

What we count

The app keeps a usage log on your Mac at ~/.config/hark/usage.jsonl. It records how often reads happen, how long they last, how much of each one you listened to, which app you were in, and how many blocks of each kind the text had.

It does not record the text. Not a sentence, not a title, not a snippet. There is nothing in that file that could reconstruct what you read.

During beta this file stays on your Mac. If we ever send it anywhere, we will say so in the app before it happens, and it will still contain no text.

Feedback you send

If you rate a read or write us a note, we keep what you wrote along with the rating. Write as much or as little as you like, and treat it as something we will read.

Deleting it

Everything the app stores is in ~/.config/hark/. Delete that folder and nothing of yours remains. Removing the app itself removes nothing else, because there is nothing else.

Getting in touch

Use Send feedback in the menu bar, or the Feedback tab in the dashboard.
