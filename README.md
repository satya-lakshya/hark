# Hark

Hark is an MVP Mac menu-bar app that reads AI answers aloud. Tap Ctrl twice and it reads the latest ChatGPT or
Claude answer in a local Kokoro voice.

- Reads the newest answer in ChatGPT or Claude, or the text you selected, or what you last copied
- The voice is Kokoro, running locally on your Mac
- macOS 14 or later, Apple silicon. Free while in beta
- Not code-signed yet, so macOS asks you to allow it in System Settings (steps on the site)

**This repository holds the landing page and the published build only. The app's source code is not here.**
